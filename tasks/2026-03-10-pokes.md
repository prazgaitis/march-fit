# 2026-03-10: Facebook-style Pokes

Users can poke any other user by visiting their profile. The pokee receives a notification with a "Poke back" action button. Partner cards for mini games have a poke button too.

## Changes

- [ ] Add `pokes` table to schema (pokerId, pokedId, challengeId, createdAt) — modeled as a precursor to chat
- [ ] Create `mutations/pokes.ts` with `poke` mutation (rate-limited via notification rollup)
- [ ] Add `"poke"` to notification rollup types with actor-based dedup
- [ ] Add poke icon, message, link, and "Poke back" button to notifications list
- [ ] Add Poke button on user profile page (next to Follow button)
- [ ] Add Poke button on partner week card

## Implementation Notes

- Pokes table tracks who poked whom in which challenge, designed as a lightweight interaction that could evolve into chat
- Notification dedup prevents spamming (1-hour rollup window, actor-based)
- "Poke back" button on notification mirrors "Follow back" pattern
